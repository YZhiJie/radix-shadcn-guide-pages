2.4 DropdownMenu / Select：菜单与选择器 ​

漫画引入 ​

小 R：用户菜单我用 Select 做的，结果点「退出登录」还要先选中再提交，怪得很。

老 S：Select 是「选一个值」，DropdownMenu 是「执行一个动作」。你把命令菜单塞进了取值控件。

小 R：那菜单里想放勾选状态呢？

老 S：用 CheckboxItem 或 RadioGroup，Radix 会把状态与键盘行为一起处理好。

学习目标 ​

  • 区分「动作菜单」与「取值选择器」的语义与适用场景。
  • 掌握 DropdownMenu 的组合结构、子菜单、勾选项、单选组与危险项。
  • 掌握受控 Select 的 value / onValueChange，并接入表单。
  • 理解两套组件的键盘模型与碰撞检测行为。

概念讲解 ​

语义差异 ​

维度DropdownMenuSelect
目的触发命令选择一个值
代表场景用户菜单、行操作、导出角色、语言、状态、分页大小
选中态通常没有（勾选项除外）有明确的当前值
表单集成不参与表单需要隐藏 input 或受控状态
关闭时机点击任意项后关闭选中后关闭

判断方法：如果点击某项后「要做一件事」，用菜单；如果点击后「值变了并要提交」，用 Select。

DropdownMenu 结构 ​

tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant="outline">用户菜单 <ChevronDown /></Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent align="start" className="w-56">
    <DropdownMenuLabel>我的账户</DropdownMenuLabel>
    <DropdownMenuSeparator />
    <DropdownMenuItem>个人资料 <DropdownMenuShortcut>⌘P</DropdownMenuShortcut></DropdownMenuItem>
    <DropdownMenuCheckboxItem checked={showStatus} onCheckedChange={setShowStatus}>
      显示状态栏
    </DropdownMenuCheckboxItem>
    <DropdownMenuSub>
      <DropdownMenuSubTrigger>邀请成员</DropdownMenuSubTrigger>
      <DropdownMenuSubContent>
        <DropdownMenuItem>通过邮件邀请</DropdownMenuItem>
        <DropdownMenuItem>复制邀请链接</DropdownMenuItem>
      </DropdownMenuSubContent>
    </DropdownMenu>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive">退出登录</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>

要点：

  • DropdownMenuContent 自动 Portal，并处理翻转与视口碰撞。
  • DropdownMenuItem 的 variant="destructive" 只影响样式，删除逻辑仍需你自己实现。
  • 勾选项是受控的：checked 与 onCheckedChange 配套使用。
  • 子菜单用 Sub / SubTrigger / SubContent，桌面端悬停展开，键盘用左右方向键进出。
  • DropdownMenuShortcut 只是右对齐的提示文本，不会真的绑定快捷键。

Select 的受控用法 ​

tsx
const [role, setRole] = useState('editor')

<Select value={role} onValueChange={setRole}>
  <SelectTrigger className="w-52">
    <SelectValue placeholder="选择角色" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel>常用角色</SelectLabel>
      <SelectItem value="viewer">只读成员</SelectItem>
      <SelectItem value="editor">编辑者</SelectItem>
      <SelectItem value="admin">管理员</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>
  • SelectValue 会显示当前项的文本，不要自己拼字符串。
  • SelectItem 的 value 不能是空字符串；需要「清空」时用一个显式的 "none" 值，或额外提供清空按钮。
  • 长列表用 SelectGroup + SelectLabel 分组，视觉与读屏都更清晰。

Select 与表单 ​

原生表单提交只认 <input> / <select>。Radix Select 是自定义控件，需要：

tsx
<Select value={role} onValueChange={setRole}>
  {/* ... */}
</Select>
<input type="hidden" name="role" value={role} />

或者直接用 React Hook Form 的 Controller 把 value / onChange 接进去（进阶篇会详细讲）。

键盘模型 ​

两套组件共享 Radix 的菜单行为：

按键行为
↑ / ↓在菜单项之间移动
Home / End跳到首项 / 末项
字母键按首字母查找（typeahead）
→ / ←进入 / 退出子菜单
Enter / Space确认当前项
Esc关闭并归还焦点

Select 额外支持输入字符快速跳转，适合国家、语言这类长列表。

可运行示例 ​

完整工程见 examples/06-menus。

bash
cd examples/06-menus
pnpm install
pnpm dev

页面包含：

  1. 用户菜单：普通项、快捷键提示、分隔线、勾选项、子菜单、危险项。
  2. 角色选择器：受控 Select + 当前值展示。
  3. 密度选择器：size="sm" 的小尺寸 Select。
  4. 通知频率：DropdownMenu + RadioGroup 的单选长列表。
  5. 键盘操作清单。

验证重点：

  • 打开菜单后按 ↓ 逐项移动，输入 p 应跳到「个人资料」。
  • 勾选「显示状态栏」，页面下方的状态文本同步变化。
  • 切换角色 Select，当前值 文本同步更新。
  • 鼠标移到「邀请成员」上，子菜单自动展开；键盘用 → 进入。

常见坑 FAQ ​

Q：Select 的 value 传空字符串，为什么占位符不显示？

Radix 把空字符串视为「已选中的空值」，不会回退到 placeholder。初始值用 undefined，或使用一个明确的 "none" 项。

Q：DropdownMenu 和 Popover 都能弹出面板，怎么选？

内容是「一组命令」且需要键盘 roving focus，用 DropdownMenu；内容是表单、说明、任意布局，用 Popover。

Q：菜单项的点击处理写在哪？

写在 DropdownMenuItem 的 onClick 或 onSelect 上。onSelect 在键盘确认时也会触发，推荐用它。

Q：为什么 SelectTrigger 放进 flex 容器后宽度不听话？

组件默认 w-fit。外层给 w-full 或直接给 Trigger 加 className="w-full"。

Q：长列表卡顿怎么办？

Select 会渲染全部选项。上百项时考虑虚拟滚动（如 TanStack Virtual），或改成带搜索的命令面板（Combobox）。
