2.3 Dialog / Popover / Tooltip：浮层三件套 ​

漫画引入 ​

小 R：我把删除确认做成了 Tooltip，用户鼠标一移开就关掉了，还点不到「确认」。

老 S：Tooltip 只做说明，不承载操作。需要阻断流程用 Dialog，需要临时面板用 Popover。

小 R：那它们底层不是同一套东西吗？

老 S：都走 Radix 的浮层能力，但模态性、焦点策略、关闭行为完全不同。选错组件，无障碍和交互一起坏。

学习目标 ​

  • 根据「是否阻断页面」「是否承载操作」选择 Dialog / Popover / Tooltip。
  • 理解 Portal、asChild、受控/非受控、定位属性与碰撞检测。
  • 掌握三个组件的组合结构与必备无障碍节点（Title / Description）。
  • 能独立写出删除确认、分享面板、快捷键提示三个典型场景。

概念讲解 ​

选择标准 ​

维度DialogPopoverTooltip
模态性模态，遮罩阻断非模态非模态
焦点圈定在内容内，关闭后归还可自由移动不抢焦点
触发方式点击点击悬停 / 键盘聚焦
承载内容确认、表单、详情分享、筛选、设置纯文本说明、快捷键
关闭Esc、遮罩、关闭按钮Esc、点击外部移出 / 失焦 / Esc

一句话：要用户做决定用 Dialog，要临时操作面板用 Popover，只是解释用 Tooltip。

共同底座：Portal 与 asChild ​

三个组件的浮层内容都会渲染到 document.body 下的 Portal，避免被父级的 overflow: hidden、transform、z-index 裁切。

asChild 是 Radix 的组合模式：Trigger 不渲染自己的 DOM，而是把事件与 ARIA 属性合并到唯一子元素上。

tsx
<DialogTrigger asChild>
  <Button variant="destructive">删除项目</Button>
</DialogTrigger>

注意子元素必须是单个可接收 ref 的元素。包一层 <div> 或写成 Fragment 都会失效。

Dialog 的最小完整结构 ​

tsx
<Dialog>
  <DialogTrigger asChild><Button>打开</Button></DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>确认删除？</DialogTitle>
      <DialogDescription>删除后 30 天内可恢复。</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose asChild><Button variant="outline">取消</Button></DialogClose>
      <DialogClose asChild><Button variant="destructive">确认</Button></DialogClose>
    </DialogFooter>
  </DialogContent>
</Dialog>
  • DialogTitle 与 DialogDescription 不是装饰：Radix 会分别映射为 aria-labelledby 与 aria-describedby。缺失时控制台会警告。
  • DialogContent 内部已包含 Portal、Overlay 与右上角关闭按钮（showCloseButton 默认 true）。
  • 关闭后焦点自动回到 Trigger，这是 Radix 的 focus scope 行为。

Popover 的定位 ​

tsx
<Popover>
  <PopoverTrigger asChild><Button>分享</Button></PopoverTrigger>
  <PopoverContent align="start" sideOffset={4} className="w-80">
    ...
  </PopoverContent>
</Popover>
  • side：top | right | bottom | left，默认 bottom。
  • align：start | center | end。
  • sideOffset：与触发器的间距。
  • 空间不足时自动翻转（collision detection），不需要手写判断。

浮层内的表单控件需要自己管理焦点顺序；Popover 不会像 Dialog 那样圈定焦点。

Tooltip 的 Provider ​

tsx
<TooltipProvider delayDuration={300}>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button size="icon" aria-label="加粗"><Bold /></Button>
    </TooltipTrigger>
    <TooltipContent>加粗 <kbd>⌘B</kbd></TooltipContent>
  </Tooltip>
</TooltipProvider>
  • TooltipProvider 通常放在应用根部，统一控制延迟；缺少它，Tooltip 无法工作。
  • Tooltip 内容会被读屏器朗读，但不应包含交互元素。
  • 对只能 hover 的桌面场景，Tooltip 是增强；键盘用户通过 focus 也能触发。
  • 移动端没有 hover，重要信息不要只放在 Tooltip 里。

动画钩子 ​

shadcn 组件用 data-open: / data-closed: 变体驱动 tw-animate-css：

tsx
className="data-open:animate-in data-open:fade-in-0 data-open:zoom-in-95
           data-closed:animate-out data-closed:fade-out-0 data-closed:zoom-out-95"

这些 data-* 属性由 Radix 在状态切换时写入，不需要自己维护 isOpen 类名。

可运行示例 ​

完整工程见 examples/05-overlays。

bash
cd examples/05-overlays
pnpm install
pnpm dev

页面包含三张卡片，分别演示：

  1. 删除确认 Dialog：Esc、遮罩、按钮三种关闭方式；关闭后焦点回到触发按钮。
  2. 分享 Popover：只读链接 + 复制按钮；点击外部关闭，不锁定页面滚动。
  3. 工具栏 Tooltip：悬停与键盘聚焦都能触发；内容包含快捷键 kbd。

验证重点：

  • 打开 Dialog 后连续按 Tab，焦点不会跑到背后的页面。
  • Popover 打开时仍可滚动页面、点击其他区域。
  • 用键盘 Tab 到工具栏图标，Tooltip 应出现；按 Esc 关闭。

常见坑 FAQ ​

Q：Tooltip 包在 disabled 按钮上不显示？

disabled 元素不触发鼠标事件。用一个 <span> 包裹按钮，把 TooltipTrigger 放在 span 上；或用 aria-disabled 替代 disabled 并自行拦截点击。

Q：Dialog 里再开 Popover 为什么会关闭整个 Dialog？

点击 Popover 内容时，点击事件可能被 Dialog 视为「外部点击」。确认 Popover 的 Portal 在 Dialog 内容树内，或使用受控模式避免误关闭。

Q：asChild 报了「children 必须是单个元素」？

检查是否多包了一层 Fragment、条件渲染返回了数组，或子元素是自定义组件但没有转发 ref 与 props。

Q：浮层被父级裁切 / z-index 失效？

Radix 默认 Portal 到 body，理论上不会被裁切。若你传了 container 或自定义 Portal，确认容器没有 overflow: hidden。

Q：Dialog 打开后页面仍能滚动？

shadcn 的 DialogContent 没内置滚动锁定时，可加 onOpenAutoFocus / 样式，或在打开时给 body 加 overflow-hidden。Radix 的 Dialog 原生支持 modal 模式下的滚动锁定，确认没有关闭 modal。

练习与延伸 ​

  1. 把删除确认改成受控 Dialog，用 open / onOpenChange 在删除成功后关闭。
  2. 给 Popover 加一个「复制成功」的临时状态，2 秒后恢复。
  3. 用 side="right" 和 align="start" 做一个右侧设置面板。
  4. 阅读 Radix Dialog 与 Popover 的 Accessibility 章节。
