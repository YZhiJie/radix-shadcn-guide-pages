2.1 Tailwind 核心工具类 ​

漫画引入 ​

小 R：我写了个卡片，margin-left: 16px 改成 margin-left: 18px，结果整个列表都错位了。

老 S：因为你每个间距都是手写像素。Tailwind 的 gap-4、p-6 用的是同一套标尺，改一个类名，整块布局跟着走。

小 R：那遇到设计稿写 37px 怎么办？

老 S：先问设计能不能对齐标尺；真不行再用任意值 w-[37ch] 兜底，但别让它变成常态。

学习目标 ​

  • 用统一标尺写间距、尺寸、圆角，而不是猜像素值。
  • 用 Flex 与 Grid 表达一维、二维布局，理解 gap 的优先级。
  • 掌握响应式前缀、状态变体、group / peer 的用法。
  • 知道何时使用任意值，以及为什么 @apply 不应成为默认选择。

概念讲解 ​

工具类的工作方式 ​

一个元素最终的样式，是这些类的并集：

tsx
<div className="flex items-center gap-4 rounded-xl border border-border bg-card p-6 shadow-sm">

阅读顺序建议固定为：布局 → 盒模型 → 外观 → 状态。这样同一类组件在代码里看起来是同一个「配方」。

Tailwind v4 默认间距标尺以 0.25rem（4px）为步长：p-1 = 4px，p-4 = 16px，p-6 = 24px。字号、圆角、阴影各有独立标尺，不要混用。

布局：Flex 管一维，Grid 管二维 ​

tsx
{/* 一行：导航、按钮组、标签 */}
<div className="flex flex-wrap items-center gap-3">
  <Button>保存</Button>
  <Button variant="outline">取消</Button>
  <span className="ml-auto text-xs text-muted-foreground">已自动保存</span>
</div>

{/* 一组卡片：列数随断点变化 */}
<div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">
  {items.map((item) => <Card key={item.id} />)}
</div>
  • 子项间距一律用 gap-*，不要给每个子项写 mr-*，最后一个元素的右边距迟早出问题。
  • ml-auto 是 flex 里最便宜的「推到右侧」方案，比 justify-between 更适合「只有一个元素靠右」的场景。
  • Grid 的列可以任意值：grid-cols-[1fr_auto]，适合「内容 + 固定操作区」。

排版：字号、字重、行高三件套 ​

tsx
<h1 className="text-3xl font-semibold tracking-tight">标题</h1>
<p className="text-base leading-7 text-muted-foreground">正文使用更松的行高。</p>
<p className="text-xs uppercase tracking-widest text-muted-foreground">辅助标签</p>

经验值：

场景组合
页面标题text-3xl font-semibold tracking-tight
卡片标题text-base font-medium
正文text-sm leading-6 或 text-base leading-7
辅助信息text-xs text-muted-foreground

行高不要全靠默认值。中文正文在 leading-6 / leading-7 下明显更易读。

颜色：优先语义 token ​

在 shadcn 工程里，bg-background、text-foreground、border-border、text-muted-foreground 会随主题变化；bg-sky-500 这类原始色阶适合图示、状态徽标，不适合大面积主题色。

tsx
{/* 业务组件：语义 token */}
<div className="border-border bg-card text-card-foreground" />

{/* 一次性视觉：原始色阶 + 透明度 */}
<span className="rounded-full bg-emerald-500/10 px-2 py-0.5 text-emerald-600">已上线</span>

响应式与状态变体 ​

Tailwind 的变体是「前缀 + 条件」：

tsx
<button className="
  rounded-lg bg-slate-900 px-4 py-2 text-white
  transition hover:bg-slate-700
  active:translate-y-px
  focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-sky-500
  disabled:cursor-not-allowed disabled:opacity-50
">
  • hover: 在触屏设备上会「粘住」，交互反馈优先 focus-visible: 与 active:。
  • 响应式是移动优先：sm: 表示 ≥640px，md: ≥768px，lg: ≥1024px。先写基础样式，再向上覆盖。
  • 断点值可在 CSS 中用 @theme 覆盖，但团队项目里不建议随意改。

group 与 peer ​

父元素加 group，后代用 group-* 响应父级状态：

tsx
<a className="group rounded-xl border p-5 transition hover:border-sky-300 hover:shadow-md">
  <h3 className="group-hover:text-sky-700">标题</h3>
  <p className="text-muted-foreground group-hover:text-foreground">描述</p>
</a>

兄弟元素之间用 peer，典型是浮动标签：

tsx
<div className="relative">
  <input id="email" placeholder=" " className="peer ..." />
  <label
    htmlFor="email"
    className="absolute left-3 top-4 transition-all
      peer-focus:top-1.5 peer-focus:text-xs
      peer-[:not(:placeholder-shown)]:top-1.5 peer-[:not(:placeholder-shown)]:text-xs"
  >
    邮箱
  </label>
</div>

注意 peer 只对后面的兄弟元素生效，DOM 顺序写反就失效。

任意值与 @apply ​

tsx
<p className="max-w-[42ch] bg-[#0f172a] grid-cols-[1fr_auto]">...</p>

任意值适合一次性需求：图表宽度、特殊网格、品牌色。出现第三次时，应该回到 @theme 定义 token。

@apply 能把工具类抽进 CSS，但会失去「就地看到样式」的优势，也容易产生新的隐式依赖。团队约定里通常只允许在全局基础层（如 @layer base）使用。

可运行示例 ​

完整页面见 examples/03-tailwind-core。

bash
cd examples/03-tailwind-core
pnpm install
pnpm dev

页面分成 7 个区块，每块对应上面一个主题：

  1. Flex 与响应式 Grid
  2. 间距标尺（p-2 / p-4 / p-6 / p-8）
  3. 排版层级
  4. 同色相明度阶梯
  5. hover / focus-visible / active / disabled
  6. group 卡片与 peer 浮动标签
  7. 任意值兜底

关键片段：

tsx
<div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">
  {['grid-cols-1', 'sm:grid-cols-2', 'lg:grid-cols-3'].map((label) => (
    <div key={label} className="rounded-xl border border-slate-200 bg-white p-5
      shadow-sm transition hover:-translate-y-1 hover:shadow-md">
      {label}
    </div>
  ))}
</div>

缩放浏览器窗口，列数会依次从 1 变 2 变 3；悬停卡片会整体上浮。这些都不需要写媒体查询。

常见坑 FAQ ​

Q：space-y-4 和 gap-4 怎么选？

能改布局就用 gap。space-y-* 依赖相邻兄弟选择器，遇到隐藏元素、动态插入、display: none 时容易留下多余间距。

Q：为什么我的 hover: 样式移动端点了不消失？

触屏没有真正的 hover。需要「按下反馈」用 active:；需要「焦点反馈」用 focus-visible:。也可以配合 @media (hover: hover) 限定。

Q：w-full 和 flex-1 有什么区别？

w-full 是宽度 100%；flex-1 是占据剩余空间（flex: 1 1 0%）。在 flex 行里想「输入框占满剩余宽度」用 flex-1 min-w-0，min-w-0 防止内容撑破。

Q：text-muted-foreground 在哪定义的？

来自 shadcn 的 @theme inline 映射。纯 Tailwind 工程没有这个类，会静默失效。用之前确认项目引入了 shadcn 的 token。

Q：类名太长怎么办？

先按「布局 / 盒模型 / 外观 / 状态」分行；重复出现的组合抽成组件（如 <Card>），而不是抽成 @apply 类。
