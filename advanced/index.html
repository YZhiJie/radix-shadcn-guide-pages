建议节奏

进阶篇不再是「这个组件怎么用」，而是「在你的项目里怎么组织」。建议先跑示例，再对照自己项目的组件目录做一次小重构。

读完你应该能 ​

  • 用 CLI 正确引入组件，并制定团队级的覆盖 / 升级约定。
  • 用一组 CSS 变量支撑多个品牌主题，组件源码零改动。
  • 判断什么该封装、什么该直接用原语，并保留 props 与 className 的逃生口。
  • 独立完成一个带异步校验、服务端错误回填的表单。
  • 独立完成一个支持排序、筛选、分页与列显隐的数据表格。
