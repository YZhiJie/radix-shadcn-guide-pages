3.5 Data Table：排序、筛选、分页与列配置 ​

漫画引入 ​

小 R：我手写了一个表格，排序要自己写 comparator，筛选要自己写 includes，翻页要自己 slice，现在产品又要「记住用户隐藏了哪些列」。

老 S：你写的其实是 TanStack Table 已经实现过三遍的东西。表格的行为归状态机，外观归 shadcn。

小 R：那我还要 <Table> 干什么？

老 S：它负责语义结构、边框和暗色适配。两者分工，代码才不打架。

学习目标 ​

  • 用 ColumnDef 声明列，理解 accessorKey 与 cell 的分工。
  • 组合核心、排序、筛选、分页四个 row model。
  • 实现全局搜索、枚举筛选、列显隐与分页控制。
  • 知道什么时候切到服务端分页 / 服务端筛选。

概念讲解 ​

两层结构 ​

text
TanStack Table  → 无 UI 的表格状态机（排序、筛选、分页、选择、列可见性）
shadcn <Table>  → 语义化的 table / thead / tbody / tr / td + 样式

TanStack 不渲染任何 DOM；它给你行模型和事件。所以同一套逻辑可以配 shadcn，也可以配任意 UI。

列定义 ​

tsx
const columns: ColumnDef<Member>[] = [
  {
    accessorKey: 'name',
    header: ({ column }) => (
      <SortHeader
        label="成员"
        sorted={column.getIsSorted()}
        onClick={() => column.toggleSorting(column.getIsSorted() === 'asc')}
      />
    ),
    cell: ({ row }) => (
      <div>
        <p className="text-sm font-medium">{row.original.name}</p>
        <p className="text-xs text-muted-foreground">{row.original.email}</p>
      </div>
    ),
  },
]
  • accessorKey 决定排序、筛选用的字段。
  • header 可以是字符串，也可以是组件；需要排序按钮时用函数形式，能拿到 column。
  • cell 只负责展示，不要在里面做数据请求。

三个 row model ​

tsx
const table = useReactTable({
  data,
  columns,
  state: { sorting, columnFilters, columnVisibility, rowSelection },
  onSortingChange: setSorting,
  onColumnFiltersChange: setColumnFilters,
  onColumnVisibilityChange: setColumnVisibility,
  getCoreRowModel: getCoreRowModel(),
  getSortedRowModel: getSortedRowModel(),
  getFilteredRowModel: getFilteredRowModel(),
  getPaginationRowModel: getPaginationRowModel(),
})

顺序很重要：先筛选，再排序，最后分页。少一个 model，对应的能力就静默失效——不报错，只是没反应。

筛选的两种粒度 ​

全局搜索：把关键词塞给某一列。

tsx
table.getColumn('name')?.setFilterValue(keyword)

自定义筛选：用 filterFn 处理枚举。

tsx
{
  accessorKey: 'status',
  filterFn: (row, id, value: string) => value === 'all' || row.getValue(id) === value,
}

更复杂的场景（日期区间、多选标签）建议把筛选状态放在组件外部，用 useMemo 预过滤 data，再交给表格——比写一个巨型 filterFn 更好维护。

列显隐 ​

tsx
table.getAllLeafColumns().map((column) => (
  <DropdownMenuCheckboxItem
    checked={column.getIsVisible()}
    onCheckedChange={(value) => column.toggleVisibility(!!value)}
  >
    {column.id}
  </DropdownMenuCheckboxItem>
))

columnVisibility 是 Record<string, boolean>，可以直接持久化到 localStorage，实现「记住用户偏好」。

渲染 ​

tsx
{table.getRowModel().rows.map((row) => (
  <TableRow key={row.id}>
    {row.getVisibleCells().map((cell) => (
      <TableCell key={cell.id}>
        {flexRender(cell.column.columnDef.cell, cell.getContext())}
      </TableCell>
    ))}
  </TableRow>
))}

flexRender 同时支持组件与普通值，不要自己判断类型。

何时切服务端 ​

数据量方案
< 1,000 行全量加载 + 客户端 model
1,000–10,000 行客户端 + 虚拟化（TanStack Virtual）
> 10,000 行 / 需要权限过滤服务端分页、排序、筛选

服务端模式要设置 manualPagination / manualSorting / manualFiltering，并把 pageCount 交给表格。此时 getPaginationRowModel 不再需要。

可运行示例 ​

完整页面见 examples/12-data-table。

bash
cd examples/12-data-table
pnpm install
pnpm dev

示例包含 18 条成员数据，支持：

  • 姓名搜索（同时匹配邮箱展示）
  • 状态筛选（全部 / 已加入 / 待接受 / 已停用）
  • 姓名、状态、席位、加入时间排序
  • 列显隐（邮箱与席位默认隐藏）
  • 每页 8 条的分页

关键片段：

tsx
<TableCell colSpan={table.getVisibleLeafColumns().length}>
  {table.getRowModel().rows.length === 0 ? '没有匹配的成员。' : null}
</TableCell>

空状态要按「可见列数」合并单元格，否则列隐藏后表头与内容错位。

常见坑 FAQ ​

Q：点了表头没反应？

九成是忘了挂 getSortedRowModel，或者没有把 sorting 状态与 onSortingChange 接上。

Q：筛选后分页还是按全量算？

getPaginationRowModel 必须排在 getFilteredRowModel 之后。客户端模式下，pageCount 会自动跟随筛选结果。

Q：row.getValue('x') 取不到值？

列必须用 accessorKey 或 accessorFn。只有 cell 的展示列没有值可取。

Q：隐藏列后布局塌了？

检查 colSpan 是否用了固定数字。用 table.getVisibleLeafColumns().length。

Q：行选择怎么做？

加一列 { id: 'select', header: ({ table }) => <Checkbox ... />, cell: ... }，并开启 enableRowSelection。当前示例只接入了状态，没有渲染选择框。

Q：表格在移动端怎么处理？

外层加 overflow-x-auto，或改成卡片列表。不要用 display: block 硬把 table 压成 div，会丢语义。

练习与延伸 ​

  1. 给示例加「席位 > 2」的数值筛选。
  2. 把 columnVisibility 持久化到 localStorage。
  3. 加一列行选择，并在底部显示「已选 3 项」。
  4. 把数据换成 5000 条，接入 TanStack Virtual 做虚拟滚动。
  5. 阅读 TanStack Table 文档。
