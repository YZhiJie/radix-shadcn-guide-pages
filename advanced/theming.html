3.2 主题系统与多品牌定制 ​

漫画引入 ​

小 R：客户想要「品牌蓝」，我把所有 bg-neutral-900 全局替换成了 bg-blue-600，结果暗色模式一片糊。

老 S：因为你换的是颜色值，不是语义。组件应该问「主色是什么」，而不是「蓝色是多少号」。

小 R：那品牌切换怎么做？

老 S：换一组 CSS 变量。组件一行不改，主题类一挂，全站跟着变。

学习目标 ​

  • 理解 shadcn 的 token 分层：基础色阶 → 语义变量 → 组件样式。
  • 掌握 @theme inline 与 :root / .dark 的配合方式。
  • 实现多品牌主题切换、圆角切换与暗色模式，并持久化用户选择。
  • 知道哪些变量该改、哪些不该碰。

概念讲解 ​

三层结构 ​

css
/* 1. 语义变量：组件的唯一依赖 */
:root {
  --primary: oklch(0.205 0 0);
  --primary-foreground: oklch(0.985 0 0);
}

/* 2. Tailwind 映射：让 bg-primary 这样的类存在 */
@theme inline {
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
}

/* 3. 组件：只写语义类 */
<Button className="bg-primary text-primary-foreground" />

注意 @theme inline 里的 inline：它让 Tailwind 生成 background-color: var(--primary)，而不是把当前值固化。没有 inline，运行时切换主题不会生效。

为什么用 oklch ​

oklch 的亮度（L）、彩度（C）、色相（H）相互独立，调整明度时不会像 HSL 那样突然改变观感。shadcn 的默认主题大量使用 oklch，做品牌色时也建议沿用：

css
.theme-ocean {
  --primary: oklch(0.55 0.16 240);
  --primary-foreground: oklch(0.985 0 0);
}

暗色模式不是简单反色，而是降低彩度、提高前景对比：

css
.dark .theme-ocean {
  --primary: oklch(0.7 0.13 240);
  --primary-foreground: oklch(0.16 0.03 240);
}

主题类的作用域 ​

把主题类挂在包裹元素上，而不是 <html>：

tsx
<div className={themeClass} style={{ '--radius': radius }}>
  <App />
</div>

好处是同一页面可以并排展示多个主题，也方便做「主题预览」这类功能。暗色模式仍建议挂在 <html>，因为浮层（Dialog、Popover）默认 portal 到 body，需要继承 .dark。

圆角与字号也走变量 ​

css
@theme inline {
  --radius-sm: calc(var(--radius) * 0.6);
  --radius-md: calc(var(--radius) * 0.8);
  --radius-lg: var(--radius);
  --radius-xl: calc(var(--radius) * 1.4);
}

只改 --radius，所有圆角档位按比例联动。字号同理，可以把 --text-* 收敛到 @theme。

持久化与防闪白 ​

主题选择存 localStorage，并在 HTML 的 <head> 里同步执行一段脚本，避免首屏先白后黑：

html
<script>
  try {
    const theme = localStorage.getItem('theme')
    if (theme === 'dark') document.documentElement.classList.add('dark')
  } catch {}
</script>

React 里的 useEffect 只能保证「挂载后正确」，不能避免闪烁。

完整页面见 examples/09-theming。

bash
cd examples/09-theming

示例提供四个品牌（Neutral / Ocean / Rose / Forest）、四档圆角、暗色开关，右侧预览面板实时联动。

关键代码：

tsx
const [theme, setTheme] = useState<ThemeName>('neutral')
const [radius, setRadius] = useState('0.625rem')

const themeClass = theme === 'neutral' ? '' : `theme-${theme}`

<div className={themeClass} style={{ '--radius': radius } as CSSProperties}>

主题 CSS 只覆盖品牌相关变量，其余继承默认值：

css
.theme-rose {
  --primary: oklch(0.6 0.19 10);
  --primary-foreground: oklch(0.985 0 0);
  --ring: oklch(0.66 0.16 10);
  --accent: oklch(0.96 0.02 10);
}

常见坑 FAQ ​

Q：切换主题后按钮没变化？

组件里写的是 bg-blue-600 这类原始色，不是 bg-primary。先统一成语义类。

Q：@theme 和 @theme inline 有什么区别？

普通 @theme 生成静态值；inline 生成 var(...) 引用。需要运行时换主题时用 inline。

Q：暗色模式下浮层还是白的？

浮层 portal 到 body，如果 .dark 挂在内部 div 上，浮层继承不到。把 .dark 挂到 <html>。

Q：自定义主题要不要把所有变量都写一遍？

不必。只覆盖品牌相关的 --primary、--ring、--accent、--chart-*。中性色共用一套，维护成本最低。

Q：能不能用 CSS 变量做字体切换？

可以。定义 --font-heading / --font-sans，在 @theme inline 映射为 --font-heading 工具类，主题类里覆盖即可。

Q：怎么校验对比度？

用浏览器 DevTools 的对比度检查，或 axe DevTools。正文至少 4.5:1，大字号至少 3:1。不要只靠肉眼。
