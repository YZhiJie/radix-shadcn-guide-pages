入门篇 · 篇章导览 ​

本篇目标：搞清楚 Radix UI、shadcn/ui、Tailwind CSS 三者的关系，搭好开发环境，写出第一个页面。

章节规划 ​

章节内容配套示例
1.1 生态关系辨析Radix UI 管行为、Tailwind 管样式、shadcn/ui 是两者的胶水—
1.2 环境搭建Node 20+、pnpm、Vite 6 + React 19 + Tailwind CSS v401-hello
1.3 第一个页面用 shadcn/ui CLI 添加组件并渲染02-first-page

运行配套示例 ​

每个示例都是独立项目，各自带 package.json 与 lockfile，互不影响：

bash
# 以 01-hello 为例
cd examples/01-hello
pnpm install
pnpm dev        # 打开终端输出的本地地址
pnpm build      # 生产构建（同时做 TypeScript 类型检查）

示例 01-hello：环境最小验证 ​

01-hello 不含任何 UI 组件库，只装了 Tailwind CSS v4 与一个 Radix 原语 @radix-ui/react-dialog：

01-hello/
├── index.html
├── vite.config.ts        # react() + tailwindcss() 两个插件
├── tsconfig.json         # strict: true
└── src/
    ├── index.css         # 只有一行：@import "tailwindcss";
    ├── main.tsx
    └── App.tsx           # Tailwind 写的卡片 + Radix Dialog

打开弹窗后试着按 Tab 与 Esc：焦点被困在弹窗内、关闭后焦点回到触发按钮——这些无障碍行为来自 Radix，而不是手写代码。页面上所有视觉样式则来自 Tailwind 工具类。

示例 02-first-page：第一个 shadcn/ui 页面 ​

02-first-page 用 CLI 初始化，并把 button、card 的源码复制进项目：

bash
pnpm create vite . --template react-ts     # 先有一个 Vite 工程
pnpm dlx shadcn@latest init -b radix -p nova
pnpm dlx shadcn@latest add button card

生成的目录里多了三样东西：

产物作用
components.jsonCLI 的配置档案：别名、CSS 变量开关、组件库基座（radix）
src/components/ui/*.tsx组件源码，归你所有，可以直接改
src/index.cssshadcn 的设计 token（CSS variables）+ @theme inline 映射

版本提示

本文写作时的 shadcn CLI 为 4.x：组件源码引用统一的 radix-ui 包与 cn 包，CSS 里额外引入 shadcn/tailwind.css。若你看到旧教程里的 @radix-ui/react-* 逐个安装、tailwind-merge 手写 cn，那是 2.x 时代的产物，思路一致、细节不同。

学习顺序

先读 1.1 建立概念地图，再按 1.2 搭环境、1.3 写出第一个页面。每章都配有可运行示例，遇到疑问先跑代码再回看文字。
