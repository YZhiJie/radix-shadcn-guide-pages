4.2 动效与过渡：让状态可被理解 ​

漫画引入 ​

小 R：我加了一堆 transition-all duration-1000，结果页面像泡在水里，点一下要等半秒。

老 S：动画不是越慢越高级。它只回答两个问题：从哪来、去哪了。

小 R：那 Accordion 展开的高度动画怎么写？max-height: 9999px？

老 S：Radix 已经把真实高度算好放在 CSS 变量里了，直接读。

学习目标 ​

  • 理解 data-state 驱动的进入 / 退出动画。
  • 用 tw-animate-css 完成常见的 fade / zoom / slide。
  • 用 --radix-accordion-content-height 实现高度过渡。
  • 尊重 prefers-reduced-motion，并只动 transform 与 opacity。

概念讲解 ​

状态选择器是核心 ​

Radix 组件把状态写在 data-state 上：

css
.accordion-content[data-state='open'] { animation: accordion-down 220ms; }
.accordion-content[data-state='closed'] { animation: accordion-up 180ms; }

不要用 .open 类名判断——那不是 Radix 的契约，升级后可能失效。

tw-animate-css 的常用组合 ​

tsx
<Badge className="animate-in fade-in-0 slide-in-from-top-1 duration-200">
类作用
animate-in / animate-out进入 / 退出动画的基类
fade-in-0 / fade-out-0透明度从 0 到 1
zoom-in-95 / zoom-out-95从 95% 放大 / 缩小
slide-in-from-top-2从上方 8px 滑入
duration-200时长

Dialog 的 DialogContent 自带 fade-in-0 zoom-in-95，遮罩自带 fade-in-0，通常不需要额外写。

高度动画 ​

css
@keyframes accordion-down {
  from { height: 0; opacity: 0; }
  to { height: var(--radix-accordion-content-height); opacity: 1; }
}
  • Radix 在每次展开前计算内容高度并写入变量，动画结束后恢复 height: auto。
  • 容器需要 overflow: hidden。
  • 内容里如果有图片，等图片加载后高度会变，考虑监听 img.onload 重新测量。

列表增删 ​

新条目用进入动画：

tsx
<Badge className="animate-in fade-in-0 slide-in-from-top-1 duration-200">

删除则要「先播放退出，再移除」：

tsx
const [removing, setRemoving] = useState<string | null>(null)

function remove(id: string) {
  setRemoving(id)
  setTimeout(() => {
    setItems((prev) => prev.filter((item) => item.id !== id))
    setRemoving(null)
  }, 150)
}

只加 animate-out 不会延迟卸载，React 会立刻把节点删掉。

时长与缓动 ​

场景时长缓动
浮层进入180–240msease-out
浮层退出120–180msease-in
Hover / 按压80–150msease-out
页面转场240–320mscubic-bezier(0.32, 0.72, 0, 1)
列表增删150–220msease-out

超过 300ms 的交互反馈会显得迟钝。退出比进入更快，符合「离开不需要解释」的直觉。

只动 transform 与 opacity ​

tsx
<div className="transition-transform duration-150 hover:-translate-y-0.5">

改 width / height / top / left 会触发布局重排。Accordion 的高度动画是例外，因为内容通常很小；大块内容应该用 transform: scaleY 或直接切换显示。

减少动效 ​

tsx
<div className="transition motion-reduce:transition-none">
css
@media (prefers-reduced-motion: reduce) {
  .accordion-content[data-state='open'],
  .accordion-content[data-state='closed'] {
    animation: none;
  }
}

motion-safe: 是反向写法：只在允许动效时应用。两者选一个一致的策略，不要混用。

常见坑 FAQ ​

Q：animate-in 没效果？

确认 src/index.css 里有 @import "tw-animate-css";。另外 animate-in 需要配合具体的 fade-in-0 这类动画类。

Q：Dialog 关闭动画不播放？

Radix 会等退出动画结束再卸载，前提是动画定义在 data-state="closed" 上。用 animate-out 系列类，而不是只在 open 时加类。

Q：Accordion 高度跳变？

内容里有异步加载元素，Radix 测量时高度还不准。等内容渲染完再展开，或用固定高度。

Q：动画期间点击错位？

动画元素仍在文档流里，transform 不影响布局，但 height 动画会影响。尽量只对 transform / opacity 做交互反馈。

Q：为什么 hover 动画在移动端卡住？

触屏没有 hover，点击后 hover 状态会保留。把 hover 效果包在 @media (hover: hover) 里，或改用 active:。

Q：能直接用 Framer Motion / Motion 吗？

可以，尤其是需要编排、拖拽、手势时。但简单浮层用 CSS 更轻，也不会引入额外运行时。先用 CSS，复杂场景再上库。

练习与延伸 ​

  1. 给删除标签实现「先退出再移除」的完整逻辑。
  2. 把 Accordion 的时长改成 180ms，观察手感差异。
  3. 用 motion-safe:animate-in 重写标签进入动画，确保减少动效时不动。
  4. 给 Dialog 加 slide-in-from-bottom-2，对比 zoom 的观感。
  5. 阅读 tw-animate-css 文档 与 Radix 的 data-state 约定。
